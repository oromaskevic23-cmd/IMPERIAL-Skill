# Production Release Gates

**Current state:** coded, testable research-stage Enterprise Skills framework. Not deployed as a production execution service.

- [ ] Actual Owner Ed25519 public key securely enrolled with separately verified Owner identity
- [ ] Independent delegated AI Passport issuer, holder binding and durable server-side revocation
- [ ] Signed, nonreplayable and narrowly scoped Owner Approval Gateway token
- [ ] Named federated orchestrator with real authenticated worker, isolation and heartbeat
- [ ] Per-NCA independent held-out professional exam; not merely an offline reference match
- [ ] Real VELION / LLM task, execution proof and test against adversarial conditions
- [ ] Independent QA signer and signed ProofGraph receipt, with external evidence where appropriate
- [ ] Process-level Owner Kill Switch, rollback and incident tests
- [ ] Legal review and separately scoped production release with no unintended financial rights

All items stay unchecked until evidence is recorded. FREE_ONLY, Zero Trust, Public/Private and CRYPTO IMPERIAL Ecosystem boundaries remain mandatory.

## Source-review gate — implemented, but not a production permit

[Source-release review](SOURCE_RELEASE_REVIEW.md) now verifies the exact
Skill/manifest/exam/dependency hashes and supports a short-lived signed source
review using a separate pinned Ed25519 reviewer key. Review means only
that source was reviewed; it **never** automatically checks any of the
production requirements above. The reviewer private key is not bundled.
