## Implementation

The Skill produces 100 deterministic symbolic NCA identities, grouped 10 × 10 into requirements, software engineering, independent review, defensive security, integration, data quality, reliability, documentation, performance and research. "Independent review" is only a planned job function, not completed independent QA. Task SHA-256 values bind mission ID, source digest, agent ID and squad. A bounded batch planner proposes up to 10 parallel slots but dispatches zero jobs. Synthetic receipt checks deny duplicate or unknown IDs, wrong task digests and fake PASS/production status.

## Evidence limitations

- Planned symbolic identities: 100. Verified live workers created by this Skill: 0.
- Example at max_parallel=10 yields 10 planned batches; actual jobs dispatched: 0.
- Owner approvals, issued AI Passports, active worker leases, real Guardian checks, independent QA, model calls, continuous uptime and production scale remain unverified.
- SHA-256 comparison is byte consistency, not proof of correctness or agent competency.
- Source tests cannot substitute for real-world load, availability, adversarial security or operator acceptance.

## Release gates

1. Validate deterministic source and negative tests under protected CI.
2. Verify one real signed HANTER → federated orchestrator → NCA worker end-to-end, including independent QA, rollback and Kill Switch.
3. Individually certify 10 workers and test enforced quotas and failure recovery.
4. After independent evidence, admit up to 100 distinct workers; validate revocation, idempotency, concurrency, data separation and financial boundary.
